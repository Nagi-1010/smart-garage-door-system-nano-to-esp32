# Components List

## Arduino Nano Version
The following components were used in the first version of the project:

- Arduino Nano
- L298N motor driver module
- DC motor / garage door actuator mechanism
- Open push button
- Close push button
- Stop push button
- 2 limit switches
- 3 LEDs for status indication
- Current limiting resistors for LEDs
- Breadboard
- Jumper wires
- External power source
- Prototype mechanical door model

## ESP32 Version
The following components were used in the upgraded version:

- ESP32 development board
- L298N motor driver module
- DC motor / garage door actuator mechanism
- IR sensor module
- 2 limit switches
- Breadboard
- Jumper wires
- Wi-Fi connection
- Blynk mobile application
- External power source
- Prototype mechanical door model

## Shared Functional Parts
Some parts were conceptually shared between both versions:

- Motorized door movement mechanism
- Limit switch-based position detection
- Embedded control logic
- Breadboard prototyping setup
- Manual and automatic control concepts

## Software and Tools
The following software platforms and tools were used during development:

- Arduino IDE
- ESP32 board support package
- Blynk IoT platform
- Wi-Fi networking
- LogixPro PLC simulation software (as design reference)

## Notes
- The Arduino Nano version was designed as a PLC-inspired embedded prototype.
- The ESP32 version upgraded the system to a smarter IoT-based implementation.
- Some hardware connections may vary slightly depending on the available boards and lab setup.
