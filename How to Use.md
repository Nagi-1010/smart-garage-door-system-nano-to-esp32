Arduino Nano: Version
Upload the Nano code to the Arduino Nano board.
Connect the buttons, motor driver, LEDs, and limit switches according to the circuit.
Press:
Open to open the door
Close to close the door
Stop to stop the door
Observe the door state using the lamps.
